앱 열기

앱을 올리는 순서

  1. Coolify 관리 화면에서 Projects → Add New Resource를 누릅니다.
  2. GitHub 저장소(Dockerfile 포함) 또는 도커 이미지 이름을 고릅니다.
  3. 앱이 듣는 포트(예: 8000)를 Ports Exposes에 적습니다.
  4. AWS 키 같은 비밀값은 Environment Variables에 넣습니다. 이미지 안에 넣지 마세요.
  5. Deploy를 누르고, 로그가 끝나면 받은 주소로 접속해 확인합니다.

이 포탈은 로컬 테스트용입니다(WSL2 + Coolify). 실제 서버에 올리면 주소만 회사 도메인으로 바뀝니다.
